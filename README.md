# LLM-ALSO

This repository contains the anonymized implementation for the submitted paper on adaptive learning-signal optimization in cooperative multi-agent reinforcement learning.

The released code includes the main components of the proposed method:

- structured PBRS reward-shaping implementation;
- staged workflow for initial dense-reward search and checkpoint-level branch validation;
- fixed reward-shaping and single-LLM reward-generation baselines;
- LLM prompt templates and workflow configuration files.



Reported evaluation in the paper is based on the original sparse task reward.
